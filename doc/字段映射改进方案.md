# 字段映射与人工修正方案 - 改进版

## 📋 当前实现评估

### ✅ 已实现的功能
1. **EnhancedFieldMatcher** - 四层匹配机制（精确/模糊/别名/语义）
2. **FieldMapping.vue** - 字段映射预览和人工修正界面
3. **知识库系统** - 自动学习和保存映射关系
4. **Excel导出** - 应用字段映射到最终输出

### ⚠️ 存在的问题

#### 问题1：前端字段选择与后端提取脱节
```
用户在Extract.vue选择协议字段 → 后端DocumentParser提取文档字段
                ↓                              ↓
        [参数, 数据类型, 单位]          [参数名称, 类型说明, 单位]
                ↓                              ↓
            没有关联！                    独立处理！
```

**影响**：用户选择的字段和实际提取的字段可能完全不匹配

#### 问题2：映射时机太晚
- 当前流程：提取完成 → 用户手动打开FieldMapping页面 → 配置映射
- 问题：用户可能直接下载结果，跳过映射步骤

#### 问题3：缺少上下文信息
- 字段匹配时没有利用用户选择的协议字段作为参考
- 无法根据文档类型（BC-RT1、BC-RT2等）自动调整匹配策略

## 🎯 改进方案

### 方案A：智能预映射（推荐）⭐

**核心思路**：在提取前，利用用户选择的协议字段作为"期望字段"，提取时优先匹配这些字段。

#### 实现步骤：

**1. 增强提取接口 - 传递期望字段**


**2. 提取时预映射**

```python
# backend/services/table_detector.py
class DocumentParser:
    def parse_with_expected_fields(self, doc_path, expected_fields):
        """带期望字段的智能提取"""
        # 提取原始表格
        raw_tables = self._extract_tables(doc_path)
        
        for table in raw_tables:
            # 提取表头
            extracted_headers = table['headers']
            
            # 预映射：将提取的表头映射到期望字段
            mapped_headers = self._pre_map_headers(
                extracted_headers, 
                expected_fields
            )
            
            table['original_headers'] = extracted_headers
            table['mapped_headers'] = mapped_headers
            table['mapping_confidence'] = self._calculate_confidence(mapped_headers)
        
        return raw_tables
    
    def _pre_map_headers(self, extracted, expected):
        """预映射表头到期望字段"""
        matcher = FieldMatcher()
        mapping = {}
        
        for ext_field in extracted:
            # 优先在期望字段中查找匹配
            best_match = matcher.find_best_match(
                ext_field, 
                expected,
                threshold=0.6  # 降低阈值，更宽松
            )
            
            if best_match:
                mapping[ext_field] = best_match['field']
            else:
                # 未匹配到期望字段，标记为待处理
                mapping[ext_field] = None
        
        return mapping
```

**4. 映射质量评分**

```python
# backend/services/field_matcher.py
def calculate_mapping_quality(self, mapping_results):
    """计算映射质量评分"""
    total = len(mapping_results)
    if total == 0:
        return {'score': 0, 'level': 'unknown'}
    
    exact_count = sum(1 for r in mapping_results if r['type'] == 'exact')
    fuzzy_count = sum(1 for r in mapping_results if r['type'] == 'fuzzy')
    unmatched_count = sum(1 for r in mapping_results if not r['matched'])
    
    # 加权评分
    score = (exact_count * 1.0 + fuzzy_count * 0.7) / total
    
    return {
        'score': score,
        'level': 'excellent' if score > 0.9 else 'good' if score > 0.7 else 'poor',
        'exact_count': exact_count,
        'fuzzy_count': fuzzy_count,
        'unmatched_count': unmatched_count,
        'total': total
    }
```

### 方案B：智能字段推荐（辅助）

**核心思路**：当文档字段无法匹配时，基于上下文智能推荐。

#### 增强推荐算法：

```python
# backend/services/field_matcher.py
def suggest_with_context(self, field_name, context):
    """
    基于上下文的智能推荐
    
    Args:
        field_name: 待匹配字段名
        context: {
            'expected_fields': [...],  # 用户选择的期望字段
            'document_type': 'BC-RT1',  # 文档类型
            'table_name': '信息定义',   # 表格名称
            'nearby_fields': [...]      # 相邻字段
        }
    """
    suggestions = []
    
    # 1. 优先推荐期望字段中的相似项
    if context.get('expected_fields'):
        for exp_field in context['expected_fields']:
            similarity = self._calculate_similarity(field_name, exp_field)
            if similarity > 0.5:
                suggestions.append({
                    'field': exp_field,
                    'similarity': similarity,
                    'reason': '用户选择的协议字段',
                    'priority': 'high'
                })
    
    # 2. 基于文档类型推荐
    if context.get('document_type'):
        protocol_fields = self._get_protocol_specific_fields(
            context['document_type']
        )
        for pf in protocol_fields:
            similarity = self._calculate_similarity(field_name, pf)
            if similarity > 0.6:
                suggestions.append({
                    'field': pf,
                    'similarity': similarity,
                    'reason': f'{context["document_type"]}协议常用字段',
                    'priority': 'medium'
                })
    
    # 3. 基于相邻字段推荐（字段通常成组出现）
    if context.get('nearby_fields'):
        # 例如：如果相邻有"数据类型"，当前字段可能是"长度"或"单位"
        field_groups = {
            ('数据类型', '长度', '单位'),
            ('参数', '内容', '备注'),
            ('信源', '信宿', '接口名称')
        }
        
        for group in field_groups:
            if any(nf in group for nf in context['nearby_fields']):
                for gf in group:
                    if gf not in context['nearby_fields']:
                        similarity = self._calculate_similarity(field_name, gf)
                        if similarity > 0.4:
                            suggestions.append({
                                'field': gf,
                                'similarity': similarity,
                                'reason': '字段组合推荐',
                                'priority': 'low'
                            })
    
    # 按优先级和相似度排序
    priority_order = {'high': 3, 'medium': 2, 'low': 1}
    suggestions.sort(
        key=lambda x: (priority_order[x['priority']], x['similarity']),
        reverse=True
    )
    
    return suggestions[:5]  # 返回前5个推荐
```

```python
# backend/services/mapping_template_manager.py
class MappingTemplateManager:
    def auto_select_template(self, document_info):
        """根据文档信息自动选择映射模板"""
        templates = self._load_templates()
        
        for template in templates:
            conditions = template.get('auto_apply_conditions', {})
            
            # 检查文档内容
            if 'document_contains' in conditions:
                if any(kw in document_info['content'] 
                       for kw in conditions['document_contains']):
                    return template
            
            # 检查表格名称
            if 'table_name_pattern' in conditions:
                import re
                pattern = conditions['table_name_pattern']
                if re.match(pattern, document_info.get('table_name', '')):
                    return template
        
        return None
    
    def apply_template(self, extracted_fields, template):
        """应用映射模板"""
        mappings = template['mappings']
        results = []
        
        for field in extracted_fields:
            if field in mappings:
                results.append({
                    'original': field,
                    'mapped': mappings[field],
                    'confidence': 0.95,
                    'type': 'template'
                })
            else:
                results.append({
                    'original': field,
                    'mapped': None,
                    'confidence': 0.0,
                    'type': 'unmatched'
                })
        
        return results
```

## 🔄 完整工作流程（改进后）

```
1. 用户选择协议字段（Extract.vue）
   ↓
2. 上传文档，传递期望字段到后端
   ↓
3. 后端提取 + 预映射
   ├─ 尝试自动选择映射模板
   ├─ 将提取字段映射到期望字段
   └─ 计算映射质量评分
   ↓
4. 返回提取结果 + 映射质量
   ↓
5. 前端判断映射质量
   ├─ 质量好（>90%）→ 直接下载
   ├─ 质量中（70-90%）→ 提示可选修正
   └─ 质量差（<70%）→ 强制进入映射页面
   ↓
6. 用户在FieldMapping.vue修正
   ├─ 查看智能推荐（基于上下文）
   ├─ 手动选择或输入
   └─ 保存到知识库
   ↓
7. 应用映射导出Excel
```
