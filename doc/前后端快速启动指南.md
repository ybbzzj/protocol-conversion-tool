# 🚀 前后端快速启动指南

> **项目路径示例：** `/Users/username/Documents/code/schoolProject`

## ⚡ 一键启动（推荐）

**macOS/Linux：**
```bash
# 首次安装依赖
cd /your/project/path && python3 -m venv venv && source venv/bin/activate && pip install -r backend/requirements.txt && cd public && npm install && cd ..

# 启动服务（分别在两个终端运行）
# 终端1：后端服务
source venv/bin/activate && python3 -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"

# 终端2：前端服务
cd public && npm run dev
```

**Windows：**
```cmd
# 首次安装依赖
cd C:\your\project\path && python -m venv venv && venv\Scripts\activate && pip install -r backend\requirements.txt && cd public && npm install && cd ..

# 启动服务（分别在两个命令提示符运行）
# CMD1：后端服务
venv\Scripts\activate && python -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"

# CMD2：前端服务
cd public && npm run dev
```

## 🔧 环境要求

- **Python**: 3.8+ (推荐 3.10+)
- **Node.js**: 16+ (推荐 18+)
- **npm**: 8+

**验证命令：**
```bash
python3 --version && node --version && npm --version
```

## ⚡ 分步启动

### 1. 安装依赖
```bash
# macOS/Linux
cd /project/path && python3 -m venv venv && source venv/bin/activate && pip install -r backend/requirements.txt && cd public && npm install && cd ..

# Windows
cd C:\project\path && python -m venv venv && venv\Scripts\activate && pip install -r backend\requirements.txt && cd public && npm install && cd ..
```

### 2. 启动后端（终端1）
```bash
source venv/bin/activate && python3 -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"
```

### 3. 启动前端（终端2）
```bash
cd public && npm run dev
```

## 🛠️ 常见问题

### Python环境问题
```bash
# 创建虚拟环境解决权限问题
python3 -m venv venv && source venv/bin/activate  # macOS/Linux
python -m venv venv && venv\Scripts\activate      # Windows
```

### 端口占用
```bash
# 检查端口占用
lsof -i :5001  # 后端端口
lsof -i :5173  # 前端端口
```

### npm安装缓慢
```bash
# 切换国内镜像
npm config set registry https://registry.npmmirror.com && npm install
```
