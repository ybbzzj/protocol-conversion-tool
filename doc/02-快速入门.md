## ⚡ 5分钟快速了解

### 项目是什么？
📊 Word协议表格信息智能提取系统

**核心功能**：
1. 从Word文档自动识别表格 ✅
2. 智能提取表格中的信息 ✅
3. 字段自动匹配到标准字段 ✅
4. 生成标准Excel输出 ✅

### 系统架构简图

```
用户上传Word文档
        ↓
   ┌─────────────┐
   │ 前端(Vue 3) │
   └──────┬──────┘
          ↓ HTTP API
   ┌──────────────────┐
   │ 后端(Python)     │
   ├──────────────────┤
   │ 表格识别         │
   │ 字段提取         │
   │ 知识库匹配       │
   │ 数据清洗         │
   └──────┬───────────┘
          ↓
   ┌──────────────────┐
   │  MySQL + Redis   │
   └──────────────────┘
          ↓
      输出Excel文件
```

## 📚 核心概念速览

### 1. 接口规范

- ✅ 所有API统一前缀：`/api`
- ✅ 统一响应格式：`{ code, message, data }`
- ✅ 错误码定义明确
- ✅ 所有接口都有详细文档

**查看**：`api.md`

### 2. 核心功能模块

| 模块 | 功能 | 对应接口 | 对应文档 |
|------|------|---------|---------|
| 文档提取 | 上传Word、提取数据 | /api/extract/* | api.md |
| 知识库 | 存储字段映射、查询建议 | /api/knowledge/* | api.md |
| 人工匹配 | 手工匹配失败时的处理 | /api/match/* | api.md |
| 仪表盘 | 任务统计、最近处理 | /api/dashboard/* | api.md |

### 3. 数据流向

```
Word文档
   ↓ (upload)
表格识别和提取
   ↓
字段匹配（知识库 + 人工干预）
   ↓
数据清洗和转换
   ↓
Excel输出
```

### 4. 知识库机制

- **精确匹配**：查询知识库中是否已有映射
- **模糊匹配**：使用Levenshtein距离查找相似字段
- **人工干预**：用户通过拖拽手动创建映射
- **自动保存**：所有映射都保存到知识库

### 5. 异步处理

- 后端使用Celery处理耗时操作
- 前端可以通过task_id查询进度
- 任务支持取消和重试
