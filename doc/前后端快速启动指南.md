## 🛠️ 常见问题

### Python环境问题
```cmd
# 创建虚拟环境解决权限问题
python -m venv venv
venv\Scripts\activate.bat
```

### Flask Debug模式问题（重要！）
```cmd
# 问题：使用debug=True时Flask重启机制在Windows下会失败
# 解决方案：确保app.py中设置debug=False
# 或者直接运行backend\app.py而不是使用-c参数

# 正确的启动方式：
python backend\app.py

# 错误的启动方式（会导致重启失败）：
python -c "from backend.app import create_app; app = create_app(); app.run(debug=True)"
```

### PowerShell执行策略问题
```powershell
# 如果遇到执行策略错误，运行以下命令
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 端口占用
```bash
# 检查端口占用
lsof -i :5001  # 后端端口
lsof -i :5173  # 前端端口
```

### npm安装缓慢
```bash
# 切换国内镜像
npm config set registry https://registry.npmmirror.com && npm install
```

```bash
# 杀掉旧进程并在后台重新启动，日志写入 server.log

  nohup python3 app.py > server.log 2>&1 &

```

#### macOS 常见问题解决
1. **模块导入错误**: 确保激活了虚拟环境 `source venv/bin/activate`
2. **端口占用**: 使用 `lsof -i :5001` 或 `lsof -i :5173` 检查
   - 杀死占用的进程：`lsof -ti :5001 | xargs kill -9`
3. **依赖缺失**: 重新运行 `pip install -r backend/requirements.txt`
4. **权限问题**: 使用虚拟环境或 `sudo` 解决权限问题
5. **npm 安装缓慢**: 使用 `npm config set registry https://registry.npmmirror.com` 切换镜像
