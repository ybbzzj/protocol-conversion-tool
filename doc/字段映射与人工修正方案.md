# 字段映射与人工修正方案

## 🎯 问题背景

当前系统中存在前端字段选择与后端实际提取字段脱节的问题：

1. **字段不匹配**: 前端选择的协议字段与后端实际从文档中提取的字段名称不一致
2. **文档字段不固定**: 测试文档中的字段名称多样化，后端只能识别预定义的字段
3. **缺少修正机制**: 后端漏识别的字段无法映射到最终结果
4. **相近字段处理**: 语义相近但名称不同的字段缺乏智能匹配能力

## 🔄 完整字段处理流程

### 新的三层映射架构：

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   原始文档字段   │───▶│   标准化字段    │───▶│   目标Excel字段  │
│ (Extracted)     │    │ (Standardized)  │    │ (Target)        │
└─────────────────┘    └─────────────────┘    └─────────────────┘
       │                       │                       │
       ▼                       ▼                       ▼
[时间戳][参数名称]    [时间戳][参数]         [时间戳][内容]
[数据类型][单位]     [数据类型][单位]      [转换类型][单位]  
[备注说明]          [备注]              [备注]
```

### 2. 后端增强 - 智能字段匹配

**增强FieldMatcher类：**

```python
# backend/services/field_matcher.py
class EnhancedFieldMatcher:
    def __init__(self):
        self.knowledge_base = self._load_knowledge_base()
        self.similarity_threshold = 0.7
        
    def match_with_context(self, extracted_fields, document_context=None):
        """
        带上下文的字段匹配
        """
        results = []
        for field in extracted_fields:
            # 1. 精确匹配
            exact = self._exact_match(field)
            if exact:
                results.append({
                    'original': field,
                    'matched': exact,
                    'confidence': 1.0,
                    'type': 'exact'
                })
                continue
                
            # 2. 模糊匹配
            fuzzy = self._fuzzy_match(field)
            if fuzzy:
                results.append({
                    'original': field,
                    'matched': fuzzy['target'],
                    'confidence': fuzzy['confidence'],
                    'type': 'fuzzy'
                })
                continue
                
            # 3. 语义匹配（二期）
            semantic = self._semantic_match(field, document_context)
            if semantic:
                results.append({
                    'original': field,
                    'matched': semantic['target'],
                    'confidence': semantic['confidence'],
                    'type': 'semantic'
                })
                continue
                
            # 4. 未匹配字段
            results.append({
                'original': field,
                'matched': None,
                'confidence': 0.0,
                'type': 'unmatched'
            })
            
        return results
    
    def suggest_similar_fields(self, field_name):
        """
        为未匹配字段推荐相似的标准字段
        """
        suggestions = []
        for std_field in self.standard_fields:
            similarity = self._calculate_similarity(field_name, std_field)
            if similarity > self.similarity_threshold:
                suggestions.append({
                    'field': std_field,
                    'similarity': similarity
                })
        return sorted(suggestions, key=lambda x: x['similarity'], reverse=True)
```

## 📊 工作流程

### 完整处理流程：

```
1. 文档上传
   ↓
2. 后端提取原始字段
   ↓
3. 前端显示提取结果预览
   ↓
4. 用户进行字段映射配置
   │
   ├── 自动匹配建议
   ├── 人工选择映射
   └── 自定义字段添加
   ↓
5. 保存映射关系到知识库
   ↓
6. 执行最终Excel导出
```

#### 步骤1：增强提取结果返回

```python
# backend/routes/extract.py
@extract_bp.route('/preview/<task_id>', methods=['GET'])
def preview_extraction(task_id):
    """预览提取结果，包括原始字段和建议映射"""
    # 获取提取的原始字段
    extracted_fields = get_extracted_fields(task_id)
    
    # 获取字段匹配建议
    matcher = EnhancedFieldMatcher()
    mapping_suggestions = matcher.match_with_context(extracted_fields)
    
    return {
        'extracted_fields': extracted_fields,
        'mapping_suggestions': mapping_suggestions,
        'unmatched_fields': [f for f in mapping_suggestions if not f['matched']]
    }
```

```javascript
function applyMapping() {
  const mappings = extractedFields.value.map(field => ({
    original: field.original,
    target: field.mapped,
    confidence: field.confidence || 0.8
  }))
  
  // 保存映射配置
  api.post('/api/mapping/apply', { 
    task_id: taskId.value,
    mappings: mappings
  })
}
```

#### 步骤3：后端应用映射规则
```python
# backend/services/excel_exporter.py
def export_with_mapping(self, tables, mapping_config):
    """使用映射配置导出Excel"""
    for table in tables:
        # 应用字段映射
        for row in table['data_rows']:
            mapped_row = {}
            for original_field, value in row.items():
                # 查找映射配置
                target_field = self.find_mapping(original_field, mapping_config)
                if target_field:
                    mapped_row[target_field] = value
                else:
                    # 保留原始字段或放入备注
                    mapped_row[original_field] = value
            
            # 处理未映射字段
            self.handle_unmapped_fields(mapped_row, mapping_config)
```
