### TC003: API接口功能测试

**测试目标**: 验证后端API的完整功能

**测试接口**:
- `GET /api/config/protocol-fields` - 获取协议字段
- `POST /api/config/protocol-fields/upsert` - 添加/更新协议字段
- `POST /api/config/protocol-fields/delete` - 删除协议字段
- `GET /api/config/target-fields` - 获取目标字段
- `POST /api/config/target-fields/upsert` - 添加/更新目标字段
- `POST /api/config/target-fields/delete` - 删除目标字段

**测试脚本**:
```python
# 协议字段API测试
def test_protocol_fields_api():
    # 获取字段列表
    response = requests.get("http://localhost:5001/api/config/protocol-fields")
    assert response.status_code == 200
    
    # 添加新字段
    new_field = {"name": "测试字段"}
    response = requests.post("http://localhost:5001/api/config/protocol-fields/upsert", json=new_field)
    assert response.status_code == 200
    
    # 验证字段已添加
    response = requests.get("http://localhost:5001/api/config/protocol-fields")
    fields = response.json()['data']['list']
    assert any(f['name'] == '测试字段' for f in fields)
```

## 🐛 常见问题和解决方案

### 问题1: 导入文件格式错误
**现象**: 导入JSON文件时提示格式错误
**解决方案**: 
- 检查JSON语法是否正确
- 确认字段结构符合要求
- 验证编码格式为UTF-8

### 问题2: 字段匹配不准确
**现象**: 字段无法正确匹配或匹配率低
**解决方案**:
- 检查字段名称是否包含关键匹配词
- 调整相似度阈值参数
- 手动添加字段别名映射

### 问题3: 数据保存失败
**现象**: 添加或修改字段后刷新页面数据丢失
**解决方案**:
- 检查后端服务状态
- 验证API接口是否正常响应
- 确认浏览器存储权限
