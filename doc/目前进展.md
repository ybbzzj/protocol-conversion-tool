
## 📋 项目详细功能说明

这是一个**Word文档协议转Excel的自动化转换工具**，专门用于从协议文档中提取表格数据，进行智能处理和融合，最终生成标准化的Excel文件。

---

## 🎯 核心功能模块

### 1️⃣ **表格识别与提取** (`table_detector.py`)

**目的**: 从Word文档中智能识别和提取所有表格，包括表头、元数据和数据行。

**具体工作流程**:

#### a) 表格定位
```
问题: Word文档中可能有多个表格，需要找到"表头"所在的行
解决方案: 
  - 扫描表格前20行，查找包含"序号"、"参数"、"类型"等关键词
  - 至少匹配3个关键字段才认定为表头
  - 如果没找到标准表头，用关键词匹配法
  - 最后还可以基于结构特征识别（如"序号+参数+类型"组合）
```

**例子**:
```
表格中的表头行可能在第3行：
| 序号 | 参数 | 数据类型 | 单位 | 备注 |
实际找表头的逻辑会扫描前面所有行，直到找到这样的组合。
```

#### b) 元数据提取
表格可能有"混合结构"——顶部有一些键值对信息（元数据），然后才是数据表。

**例子**:
```
信息名称: 某设备装置测量数据1
信息标识: —
序号 | 内容 | 类型 | 值域 | 单位
<这里才是数据行>
```

系统会：
- 识别表头上方的所有行
- 扫描这些行中的键值对（如"信息名称: 某设备装置测量数据1"）
- 提取并存储这些元数据

#### c) 数据行过滤
```
过滤规则:
  ✓ 保留: 有内容字段 + 有意义的数据
  ✗ 过滤: 
    - 全空行（没有任何内容）
    - 注释行（如"注：时间按小端处理"）
    - 噪声行（包含"参见"等词）

例子:
行1: [序号: 1 | 参数: Time | 类型: UINT32] → ✓ 保留
行2: [序号:   | 参数:       | 类型:      ] → ✗ 过滤（全空）
行3: [注：详见附录] → ✗ 过滤（注释）
```

### 2️⃣ **表格关联与融合** (`table_linker.py`)

**目的**: 识别核心表和辅助表，把辅助表的数据融合到核心表中。

**工作原理**:

#### a) 核心表判断标准
```
核心表需要满足:
  1. 有"参数/内容/信号名称"列（数据内容）
  2. 有"数据类型/类型"列（数据类型）
  3. 有有意义的协议名称（不是默认的"端口分配表"这样的名字）

例子:
表1: 某设备装置测量数据1 [内容] [类型] [单位] → ✓ 核心表
表2: ID编码表 [信息内容] [消息ID] [信源] → ✗ 辅助表（是表1的配套表）
```

#### b) 全局表融合
一旦确定了核心表，系统会扫描**所有辅助表**，查找能融合的数据。

**融合条件**: 辅助表中的"信息内容"与核心表的"信息名称"**完全相等**（精确匹配）

**例子**:

ID编码表（辅助表）:
```
| 信息内容 | 消息ID | 信源 | 信宿 |
| 某设备装置测量数据1 | 0x8001 | 某设备 | 综合模块 |
| 某设备装置测量数据11 | 0x8002 | 设备B | 模块B |
```

核心表1: 某设备装置测量数据1
```
→ 在ID表中找到精确匹配 "某设备装置测量数据1"
→ 融合该行的所有数据: 消息ID=0x8001, 信源=某设备, 信宿=综合模块
```

核心表2: 某设备装置测量数据11
```
→ 在ID表中找到精确匹配 "某设备装置测量数据11"
→ 融合该行的所有数据: 消息ID=0x8002, 信源=设备B, 信宿=模块B
```

**重点**: 这两个协议的数据是**完全不同的**，不会混淆！

### 3️⃣ **数据清洗与转换** (`data_cleaner.py`)

**目的**: 标准化数据类型，进行类型转换。

**具体工作**:

#### a) 数据类型标准化
```
输入各种格式的类型字符串，转换为标准格式

例子:
"UINTEGER-32" → UINT32 (32位)
"16位无符号整型" → UINT16 (16位)
"UINT16" → UINT16 (16位)
"32BIT无符号整型" → UINT32 (32位)
```

#### b) 位数提取
从类型字符串中自动提取位数：
```
"UINT32" → 32
"16BIT" → 16
"FLOAT64" → 64
```

### 4️⃣ **值域处理** (`excel_exporter.py`)

**目的**: 从备注或值域列中提取数据范围，统一格式。

**具体逻辑**:

#### 优先级规则
```
1️⃣ 优先: 备注中的"取值范围"
   例: 备注 = "32位整型，取值范围0~255" 
   → 提取 0~255

2️⃣ 次优先: 表格的"值域"列
   例: 值域列 = "[0, 255]"
   → 转换为 0~255

3️⃣ 再次: "数据处理方法"中的范围
   例: 方法 = "乘以10，范围0~1000"
   → 提取 0~1000

4️⃣ 最后: 其他字段中的数值
```

#### 格式统一
```
输入格式 → 统一输出格式
[0,255] → 0~255
[0-255] → 0~255
{0,1,2,3} → 0~1~2~3
0xFFFF~0x0000 → 保持不变

移除所有括号和不规范分隔符
```

**例子**:
```
原始备注: "32位整型数，LSB=1ms，以上电为零点，软件开算时刻清零。取值范围[0, 4294967295]"
→ 提取值域: 0~4294967295
```

---

### 5️⃣ **信源/信宿分解** (`excel_exporter.py`)

**目的**: 处理"信源、信宿"这样的复合字段，将其分解为独立的字段。

**识别符号**:
```
支持的分隔符（优先级从高到低）:
  1. è (特殊字符)
  2. → (箭头)
  3. - (连字符)
  4. 固定位数分解
```

**例子**:

```
输入: "BC→RT1-SA0-模式码0x03"
分解: 
  信源: BC
  信宿: RT1-SA0-模式码0x03
  
输入: "192.167.2.22：10000 → 192.167.2.28：10022"
分解:
  信源机器码: 192.167.2.22：10000
  信宿机器码: 192.167.2.28：10022
```

### 6️⃣ **Excel导出** (`excel_exporter.py`)

**目的**: 把处理后的数据填充到标准Excel模板中。

**工作流程**:

#### a) 模板准备
```
使用 协议模板.xlsx 作为基础模板
模板包含17个标准列:
名称、信源系统码、信源机器码、信宿系统码、信宿机器码、
子地址、数据段长度、ID、内容、子内容、类型、转换类型、
判读公式、转换公式、单位、备注
```

#### b) 数据映射
```
表格数据 → Excel列映射

元数据优先映射:
  消息ID → ID列
  信源 → 信源机器码列
  信宿 → 信宿机器码列

行数据映射:
  参数 → 内容列
  数据类型 → 转换类型列
  单位 → 单位列
  值域/备注 → 判读公式列（备注优先）
```

#### c) 备注处理
```
备注列只包含:
  - 原始表格中的备注内容
  - 从备注中提取的额外信息（如单位、值域）
  
NOT包含:
  - 表内的元数据（如"信息名称: xxx"）
  - 无法映射的元数据
```

**例子**:
```
原始备注: "32位整型数，LSB=1ms，以上电为零点，软件开算时刻清零。"
→ Excel备注列: 完全保留（这是数据的实际备注）

不会写入:
→ "信息名称: 某设备装置测量数据1"（这是元数据，不是备注）
```

## 🔄 完整处理流程示例

假设输入一个Word文档，包含以下表格：

### 输入表格 1: ID编码表（辅助表）
```
序号  | 信源  | 信宿   | 信息内容                 | 消息ID
1    | 某设备 | 综合模块 | 某设备装置测量数据1     | 0x8001
2    | 某设备 | 综合模块 | 某设备装置测量数据11    | 0x8002
```

### 输入表格 2: 某设备装置测量数据1（核心表）
```
信息名称: 某设备装置测量数据1
信息标识: —

代号 | 内容               | 类型         | 字节 | 值域            | 单位 | 备注
Time | 某设备计时时间     | UINTEGER-32  | 4    | 0~4294967295   | ms   | 32位整型，LSB=1ms
     | 帧计数             | UINTEGER-32  | 4    | 0~4294967295   | —    | 乘以10
```

### 处理过程:

```
第1步: 表格识别
  ✓ 识别表1为辅助表（ID编码表）
  ✓ 识别表2为核心表（有内容+类型+协议名称）

第2步: 元数据提取
  表2元数据: {信息名称: "某设备装置测量数据1", 信息标识: "—"}

第3步: 表融合
  在表1中查找 "某设备装置测量数据1" 
  → 找到！融合信源="某设备", 信宿="综合模块", 消息ID="0x8001"

第4步: 数据清洗
  UINTEGER-32 → UINT32 (32位)
  0~4294967295 → 保持（已是标准格式）
  
第5步: 值域处理
  "32位整型，LSB=1ms" 中没有范围
  → 使用表格的"值域"列: 0~4294967295

第6步: Excel导出
  行1: 名称="某设备装置测量数据1", ID="0x8001", 
       信源机器码="某设备", 信宿机器码="综合模块",
       内容="某设备计时时间", 类型="UINT32", 
       单位="ms", 备注="32位整型，LSB=1ms"
```

### 输出 (Excel)：
```
名称                    ID      信源机器码  信宿机器码   内容            类型      单位  备注
某设备装置测量数据1    0x8001  某设备      综合模块    某设备计时时间   UINT32    ms   32位整型，LSB=1ms
某设备装置测量数据1              某设备      综合模块    帧计数          UINT32    —    乘以10
```

## 🎨 关键技术特点

1. **精确匹配融合** - 使用"=="而非"in"，确保"某设备装置测量数据1"和"某设备装置测量数据11"不会混淆

2. **优先级管理** - 值域、单位等有明确的优先级（备注>表格字段>推断字段）

3. **全局表融合** - 不仅限于ID表，任何辅助表中有匹配的"信息内容"都会被融合

4. **混合结构支持** - 同时处理元数据区域和数据表区域的表格

5. **噪声过滤** - 自动识别和排除注释行、空行、参考行等

这就是这个项目的完整功能！它本质上是一个**协议文档的智能结构化工具**。
