# 字段配置快速使用指南

## 🚀 快速开始

### 1. 启动服务
```bash
# 启动后端服务
cd backend
python app.py

# 启动前端服务（新终端）
cd public
npm run dev
```

### 2. 访问配置页面
打开浏览器访问：http://localhost:5174/#/config

### 3. 导入字段配置
1. 点击"导入字段（JSON）"按钮
2. 选择配置文件：
   - `doc/核心字段配置.json` - 入门推荐
   - `doc/字段配置模板.json` - 标准配置
   - `doc/完整字段配置模板.json` - 专业配置

## ❓ 常见问题

**Q: 导入后字段没有显示？**
A: 检查JSON格式是否正确，字段名称是否重复

**Q: 如何恢复默认配置？**
A: 重新导入对应的配置模板文件

**Q: 配置文件保存在哪里？**
A: 前端保存在浏览器localStorage中，后端保存在backend/config_*.json文件中

**Q: 服务重启后配置会丢失吗？**
A: 不会，后端配置持久化保存，前端配置在同浏览器中保持
