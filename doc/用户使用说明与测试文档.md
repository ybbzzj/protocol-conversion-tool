# 用户使用说明与测试文档

---

## 一、系统概述

本系统是一个 **Word 协议表格信息智能提取与匹配工具**，可将 Word 协议文档中的表格自动识别、提取、清洗、匹配，并生成标准化的 Excel 输出文件。

**核心能力**：
- 📄 自动识别 .doc/.docx 文档中的多种表格类型
- 🔍 智能匹配字段映射（知识库 + 模糊匹配）
- 🧹 自动数据清洗（类型标准化、值域格式化、公式提取、单位识别）
- 📊 生成标准化 Excel（颜色标记：红色=推断值、蓝色=关联补充、黑色=原始值）

### 3.2 文档提取 (Extract)

这是系统的**核心功能**——上传协议 Word 文档，自动提取并导出为 Excel。

**操作步骤**：

1. **选择文件**：点击或拖拽上传一份 Word 协议文档（.doc 或 .docx）
2. **选择协议字段**（可选）：从右侧字段列表中勾选需要提取的字段类型（如"协议名称""数据类型""单位"等）。已选字段会用于映射质量评估
3. **点击"开始提取"**：系统开始处理，显示进度条
4. **等待完成**：处理完成后自动弹出下载
5. **查看结果**：下载的 Excel 文件中包含所有识别到的表格数据

**处理耗时参考**：
- 小型文档（< 10 个表格）：约 3-10 秒
- 中型文档（10-30 个表格）：约 10-30 秒
- 大型文档（30+ 个表格）：约 30-60 秒

**Excel 输出说明**：

| 列名 | 说明 |
|------|------|
| 名称 | 协议消息/表格名称（首行填写） |
| ID | 消息ID（从消息ID表关联补充，蓝色字体） |
| 信源系统码 | 信源标识（从端口分配表关联补充，蓝色字体） |
| 信宿系统码 | 信宿标识（从端口分配表关联补充，蓝色字体） |
| 序号 | 字段序号 |
| 内容 | 字段名称/内容描述 |
| 转换类型 | 标准化后的数据类型（如 UINT8, FLOAT32） |
| 类型（bit） | 数据类型位数 |
| 判读公式 | 值域范围（如 [0, 4294967295]） |
| 转换公式 | 数据处理公式（如 0.005127x+0） |
| 单位 | 物理单位 |
| 备注 | 原始备注内容 |

**颜色标记说明**：

| 颜色 | 含义 | 示例 |
|------|------|------|
| 🔴 **红色** | 自动推断/提取值，建议人工确认 | 从"字节"推断为 UINT8；从备注中提取的单位 |
| 🔵 **蓝色** | 从辅助表关联补充的元数据 | 端口分配表注入的信源系统码 |
| ⚫ **黑色** | 原始文档直接映射，可靠值 | 序号、内容等直接读取的字段 |

### 3.3 字段映射预览与修正

提取完成后，可预览字段映射结果并进行人工修正。

**操作步骤**：
1. 在提取结果页面点击"预览映射"
2. 查看自动匹配结果：
   - 🟢 绿色标记：精确匹配（confidence ≥ 0.9）
   - 🟡 黄色标记：模糊匹配（confidence ≥ 0.7）
   - 🔴 红色标记：未匹配，需人工干预
3. 对未匹配字段，可从候选建议中选择或手动输入目标字段
4. 点击"应用映射"，映射关系自动保存到知识库供后续复用

> **[需要图片]** 字段映射预览页面截图（展示匹配结果和未匹配字段的候选建议）

---

### 3.4 知识库管理 (Knowledge)

知识库存储所有已确认的字段映射关系，用于加速后续文档的自动匹配。

**功能**：
- 📋 **查看列表**：分页浏览所有映射关系（源字段 → 目标字段），显示命中次数和置信度
- 🔍 **搜索筛选**：按关键字搜索，按 table_id 筛选，按置信度筛选
- ➕ **手动添加**：直接添加新的映射关系
- ❌ **删除映射**：移除不再需要的映射条目
- 📊 **统计分析**：查看总映射数、按来源分布、热门映射排行

> **[需要图片]** 知识库管理页面截图（展示映射列表和统计信息）

### 3.5 字段配置 (Config)

配置协议字段和目标字段的标准列表。

**协议字段**：Word 文档中可能出现的字段名称列表（如"协议名称""数据类型""单位"等）

**目标字段**：输出 Excel 中期望的标准字段列表（如"名称""转换类型""判读公式"等）

> 当前前端使用 localStorage 管理，支持导入/导出 JSON 备份。后端 API 已完整实现，需要时可切换为服务端管理。

> **[需要图片]** 字段配置页面截图（展示协议字段和目标字段的编辑界面）

### 3.6 人工匹配 (Match)

当自动匹配无法满足需求时，提供拖拽式可视化人工匹配界面。

**功能**：
- 📤 上传协议文本或文档，自动解析字段
- 📥 上传目标表格，自动解析表头
- 🔗 拖拽连线建立源字段到目标字段的映射
- 💾 保存映射关系到知识库

> **[需要图片]** 人工匹配页面截图（展示拖拽连线匹配界面）

### 3.7 批量处理 (Batch) 【预留功能】

支持上传包含多个表格的 CSV/Excel 文件进行批量处理。

**功能**：
- 上传 CSV 或 Excel 文件
- 自动识别和分发处理
- 显示整体进度和文件级进度

## 五、常见问题 (FAQ)

### Q1：上传文件后一直显示"处理中"？

- 检查后端是否正常启动（访问 `http://localhost:5001/health`）
- 文档较大时处理时间较长，请耐心等待
- 查看 `backend/logs/extraction_trace.log` 日志排查

### Q2：Excel 中某些表格缺失？

- 可能被识别为干扰表自动过滤（如"帧格式表""示例表"等）
- 检查原始 Word 文档中表格的类型
- 查看 `table_recognition_results/latest_recognition.json` 确认识别结果

### Q3：字段映射不准确？

- 在知识库页面添加更多映射关系，提高后续匹配准确率
- 使用人工匹配页面进行手动修正
- 匹配质量评分低于 0.7 时建议人工复核

### Q4：启动时提示缺少依赖？

- 确保已执行 `pip install -r backend/requirements.txt`
- Windows 7 环境使用 Python 3.8 版本
- 离线环境使用 `install_offline.bat` 安装

### Q5：下载的 Excel 文件名显示乱码？

- 浏览器兼容性问题，尝试使用 Chrome 浏览器
- 下载后的文件可手动重命名

### Q6：语义匹配为什么不工作？

- 当前版本语义匹配（ERNIE 3.0 Nano）默认禁用
- 如需启用，取消 `field_matcher.py` 中 `_semantic_match` 方法的注释，并确保 `models/ernie-3.0-nano-zh/` 目录下有模型文件
