# Word协议表格信息提取系统 - 一期二期工作分配

## 项目概述

本系统用于从Word文档中自动识别和提取表格信息，并将提取的数据字段智能匹配到标准目标字段，最终生成标准化的Excel输出。

项目分为两个阶段实现：
- **第一期**：知识库精确匹配 + 人工干预系统（当前正在实现）
- **第二期**：语义匹配引擎 + 智能推荐系统（预留扩展）

|------|------|------|
| /api/dashboard/recent | GET | 获取最近任务和统计 |
| /api/extract/start | POST | 创建文档提取任务 |

#### 核心技术实现

- **文档解析**：python-docx 解析Word文档，提取所有表格
- **表头识别**：多策略识别（模板、文本特征、结构变化）
- **字段提取**：从表格中提取指定协议字段
- **字段匹配**：知识库精确匹配，失败则人工干预
- **数据清洗**：缺失字段补全、类型推断、异常标记
- **Excel输出**：openpyxl生成标准化Excel文件
- **异步处理**：Celery处理长时间任务，Redis缓存
- **任务管理**：MySQL存储任务状态和结果

## 数据结构统一规范

### 知识库表结构

```sql
CREATE TABLE knowledge_base (
    id INT PRIMARY KEY AUTO_INCREMENT,
    source VARCHAR(255) NOT NULL,         -- 源字段（协议字段）
    target VARCHAR(255) NOT NULL,         -- 目标字段
    table_id VARCHAR(255) NOT NULL,       -- 来源表格ID
    confidence FLOAT DEFAULT 1.0,         -- 置信度 [0.0-1.0]
    hits INT DEFAULT 1,                   -- 命中次数
    labeler VARCHAR(255),                 -- 标注者ID
    label_time TIMESTAMP,                 -- 标注时间
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_mapping (source, target, table_id)
);
```

### API统一响应格式

```json
{
  "code": 0,
  "message": "操作成功",
  "data": {}
}
```

**错误码定义**
- 0：成功
- 40001：参数错误
- 40002：文件解析失败
- 40401：资源不存在
- 50001：内部错误
