## 项目总体概览

### 项目定义
Word协议表格信息智能提取与匹配系统 - 从Word文档中自动识别和提取表格信息，并将提取的数据字段智能匹配到标准目标字段，最终生成标准化的Excel输出。

### 核心功能流程

```
┌────────────────────────────────────────────────────────┐
│ 1️⃣  用户上传Word文档 + 选择协议字段                    │
└─────────────────┬──────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────────────────┐
│ 2️⃣  后端自动识别表格（多策略表头识别）                 │
└─────────────────┬──────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────────────────┐
│ 3️⃣  提取表格数据（名称、内容、类型、单位、公式、备注）│
└─────────────────┬──────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────────────────┐
│ 4️⃣  字段匹配（知识库→模型推荐→人工干预）              │
└─────────────────┬──────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────────────────┐
│ 5️⃣  数据清洗（缺失补全、类型推断、异常标记）         │
└─────────────────┬──────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────────────────┐
│ 6️⃣  生成标准Excel输出                                 │
└────────────────────────────────────────────────────────┘
```

### 技术栈（简化版）
- **前端**：Vue 3 + TypeScript
- **后端**：Python + Flask
- **数据存储**：本地JSON文件 + 文件锁
- **任务处理**：Python threading（后台线程）
- **文档处理**：python-docx, openpyxl

        ]

#### 1.2 实现表头识别策略

**关键算法**：
1. 策略一：协议模板判断（检查标准列数和关键字）
2. 策略二：文本特征识别（识别特定格式行）
3. 策略三：结构变化识别（找行数/列数变化点）

### 步骤 2️⃣ 实现字段匹配模块（3天）

**目标**：实现知识库匹配和数据映射

#### 2.1 实现FieldMatcher类
**文件**: `services/field_matcher.py`

关键功能：
- `match_field()` - 分层匹配（精确→模糊→语义）
- `_exact_match()` - 精确匹配知识库
- `_fuzzy_match()` - 模糊匹配（Levenshtein距离）

**匹配优先级**：
```
第一层：知识库精确匹配 → 置信度=1.0
   ↓
第二层：模糊匹配 → 置信度=0.8*相似度
   ↓
第三层：人工干预 → 拖拽界面
```

### 步骤 4️⃣ 实现数据操作函数（1天）

**目标**：实现本地JSON文件数据操作

#### 4.1 实现数据管理模块
**文件**: `utils/data_manager.py`

```python
import json
import os
from threading import Lock

TASKS_FILE = 'data/tasks.json'
KB_FILE = 'data/knowledge_base.json'

tasks_lock = Lock()
kb_lock = Lock()

def load_tasks():
    """加载任务数据"""
    with tasks_lock:
        if not os.path.exists(TASKS_FILE):
            return {'tasks': []}
        try:
            with open(TASKS_FILE, 'r', encoding='utf-8') as f:
                return json.load(f)
        except:
            return {'tasks': []}

def save_tasks(data):
    """保存任务数据"""
    with tasks_lock:
        with open(TASKS_FILE, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

def load_knowledge_base():
    """加载知识库"""
    with kb_lock:
        if not os.path.exists(KB_FILE):
            return {'knowledge_base': []}
        try:
            with open(KB_FILE, 'r', encoding='utf-8') as f:
                return json.load(f)
        except:
            return {'knowledge_base': []}

def save_knowledge_base(data):
    """保存知识库"""
    with kb_lock:
        with open(KB_FILE, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
```
