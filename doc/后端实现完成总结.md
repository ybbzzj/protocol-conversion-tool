**完成内容**:
- [x] 集成到 `routes/extract.py`
  - `extract_task_worker()` - 后台处理函数
  - `threading.Thread` - 后台线程
  - 任务生命周期管理
  - 实时进度更新

**处理流程**:
```
用户上传文件
  ↓ (立即返回 task_id)
后台线程开始处理:
  1. 解析文档 (10% → 40%)
  2. 匹配字段 (40% → 60%)
  3. 生成Excel (60% → 90%)
  4. 保存结果 (90% → 100%)
  ↓
用户轮询查询状态
  ↓
任务完成，用户下载
```

### ✅ 步骤 6: API路由 (完成)

**目标**: 实现6个核心API接口

**完成内容**:

#### 6.1 仪表盘接口
- [x] `GET /api/dashboard/recent`
  - 返回: 最近10个任务 + 统计数据
  - 响应: `{code: 0, data: {recent, stats, kb_stats}}`

#### 6.2 文档提取接口
- [x] `POST /api/extract/start`
  - 参数: file (multipart), field_ids (JSON)
  - 返回: `{task_id}`
  - 响应: 201 Created

- [x] `GET /api/extract/status/{task_id}`
  - 返回: `{status, progress, file_name, created_at, error_message}`
  - 支持轮询

- [x] `GET /api/extract/download/{task_id}`
  - 返回: Excel文件流
  - 仅允许 status=success

#### 6.3 知识库接口
- [x] `GET /api/knowledge/list`
  - 参数: q, table_id, source, target, page, page_size
  - 返回: `{list, total, page, page_size}`
  - 支持多维度搜索和分页

#### 6.4 匹配接口
- [x] `POST /api/match/save-mapping`
  - 参数: `{table_id, mapping, labeler}`
  - 返回: `{count, table_id}`
  - 自动更新知识库

**统一响应格式**:
```json
{
  "code": 0,
  "message": "OK",
  "data": {}
}
```

**错误码说明**:
- 0: 成功
- 40001: 参数错误
- 40401: 资源不存在
- 50001: 服务器错误

**时间估算**: 4天 ✅
