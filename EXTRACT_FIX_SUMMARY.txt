【问题描述】
  ❌ 前端"文档提取"页面点击"开始提取"时，显示"创建任务失败"提示
  ❌ 任务未被创建
  ❌ 后端 API 日志无错误记录

【根本原因】
  📌 FormData 格式不匹配 - 前后端约定冲突
  
  前端代码 (错误):
    fd.append('field_ids', JSON.stringify(selectedFieldIds.value))
    // 发送: field_ids = "[\"id1\",\"id2\"]" (单个 JSON 字符串)
  
  后端期望:
    request.form.getlist('field_ids')
    // 期望: field_ids=id1&field_ids=id2 (多个表单字段)
  
  结果:
    ❌ 格式不匹配导致任务创建失败

【修复内容】
  ✅ 已修改: public/src/pages/Extract.vue (第 188-203 行)
  
  修改前:
    fd.append('field_ids', JSON.stringify(selectedFieldIds.value))
    catch(e:any){ toast.show('创建任务失败') }
  
  修改后:
    for(const fieldId of selectedFieldIds.value){
      fd.append('field_ids', fieldId)  // ✅ 为每个字段添加独立的表单字段
    }
    catch(e:any){ 
      console.error('创建任务失败:', e)
      toast.show('创建任务失败: ' + (e.response?.data?.message || e.message || '未知错误'))
    }
  
  改进:
    ✅ 修正 FormData 格式 - 前后端约定一致
    ✅ 改进错误提示 - 显示具体错误信息
    ✅ 添加调试日志 - console.error() 便于诊断

【常见问题】

Q: 修改代码后前端没有更新?
A: 1. 检查前端终端日志是否有 "hot update" 提示
   2. 如无，手动刷新: Ctrl+Shift+R
   3. 如仍无，检查前端服务是否正常运行

Q: 创建任务时仍显示 "请选择协议字段"?
A: 1. 确保已在"字段配置"页面添加了协议字段
   2. 点击"文档提取"页面的"刷新"按钮
   3. 检查字段列表是否显示

Q: 上传文件后仍然失败?
A: 1. 打开浏览器 F12 → Console 查看具体错误
   2. 确保上传的是 .doc 或 .docx 文件
   3. 检查文件大小是否过大 (通常支持 100MB 以内)
   4. 运行 python3 test_extract_fix.py 进行 API 测试

Q: 下载结果按钮无法点击?
A: 1. 等待提取完成（进度条 100%）
   2. 查看浏览器控制台是否有错误
   3. 检查文件是否已成功生成到 backend/outputs/
