# 字段映射交互方案 - 深度分析与解决方案

## 🎯 核心问题分析

### 当前问题
1. **左右字段不对等**：左边是文档提取的字段，右边是标准目标字段，数量和内容都不同
2. **连线后不删除**：连线后左右字段仍然显示，导致混乱
3. **多对一映射**：多个源字段可能映射到同一个目标字段
4. **一对多映射**：一个源字段可能需要映射到多个目标字段（较少见）
5. **未映射字段处理**：有些字段可能不需要映射，应该如何处理

---

## 📊 场景分析

### 场景1：标准映射（1对1）
```
左侧（文档字段）          右侧（目标字段）
┌─────────────┐          ┌─────────────┐
│ 参数名称     │ ────────▶│ 参数        │
└─────────────┘          └─────────────┘
```
**处理**：连线后，左右都标记为"已映射"，从待映射列表移除

### 场景2：多对一映射
```
左侧（文档字段）          右侧（目标字段）
┌─────────────┐          
│ 参数名称     │ ────────┐
└─────────────┘         │
┌─────────────┐         ├─▶ ┌─────────────┐
│ 字段名       │ ────────┤   │ 参数        │
└─────────────┘         │   └─────────────┘
┌─────────────┐         │
│ 变量名       │ ────────┘
└─────────────┘
```
**处理**：允许多个源字段映射到同一目标，但需要合并策略（优先级、拼接等）


### 场景3：字段拆分（1对多）
```
左侧（文档字段）          右侧（目标字段）
                         ┌─────────────┐
                    ┌───▶│ 信源        │
┌─────────────┐    │    └─────────────┘
│ 信源、信宿   │ ───┤
└─────────────┘    │    ┌─────────────┐
                    └───▶│ 信宿        │
                         └─────────────┘
```
**处理**：需要字段拆分逻辑，一个源字段生成多个目标字段

### 场景4：字段不存在
```
左侧（文档字段）          右侧（目标字段）
┌─────────────┐          ┌─────────────┐
│ 自定义字段A  │    ✗     │ 参数        │
└─────────────┘          └─────────────┘
                         ┌─────────────┐
                         │ 数据类型     │ ← 左边没有对应字段
                         └─────────────┘
```
**处理**：
- 左边多余字段 → 放入"备注"或"忽略"
- 右边缺失字段 → 标记为"缺失"，允许手动填充默认值

### 场景5：字段重命名
```
左侧（文档字段）          右侧（目标字段）
┌─────────────┐          ┌─────────────┐
│ 类型说明     │ ────────▶│ 数据类型     │
└─────────────┘          └─────────────┘
```
**处理**：简单的1对1映射，但需要智能推荐

## 💡 推荐解决方案

### 方案：三区域交互式映射

#### 界面布局
```
┌────────────────────────────────────────────────────────────┐
│                     字段映射工作区                          │
├──────────────┬──────────────────────┬──────────────────────┤
│  待映射字段   │    已建立的映射关系    │   目标字段池         │
│  (左侧)      │    (中间)            │   (右侧)            │
├──────────────┼──────────────────────┼──────────────────────┤
│ □ 参数名称    │ 参数名称 ──→ 参数     │ □ 参数 (1)          │
│ □ 类型说明    │ 类型说明 ──→ 数据类型 │ □ 数据类型 (1)      │
│ □ 字节长度    │                      │ □ 长度 (0)          │
│ □ 备注信息    │ [删除] [编辑]        │ □ 单位 (0)          │
│              │                      │ □ 备注 (0)          │
│ + 添加自定义  │                      │ + 添加目标字段       │
└──────────────┴──────────────────────┴──────────────────────┘
```

#### 核心特性

1. **动态列表更新**
   - 建立映射后，源字段从左侧移除（或标记为已用）
   - 目标字段显示映射数量 `(n)`
   - 中间区域显示所有已建立的映射关系

2. **智能推荐**
   - 左侧字段悬停时，右侧高亮推荐的目标字段
   - 显示相似度评分和推荐理由

3. **多种映射方式**
   - 拖拽：从左侧拖到右侧
   - 点击：点击左侧字段，再点击右侧字段
   - 快捷键：选中后按回车自动映射到推荐字段

4. **映射管理**
   - 支持删除、编辑映射关系
   - 支持批量操作（全部清除、应用模板）
   - 支持撤销/重做

### 数据结构设计

```typescript
// 映射关系数据结构
interface FieldMapping {
  id: string                    // 唯一标识
  source: string[]              // 源字段（支持多个）
  target: string                // 目标字段
  mappingType: 'one-to-one' | 'many-to-one' | 'one-to-many' | 'custom'
  confidence: number            // 置信度 0-1
  strategy?: 'merge' | 'split' | 'transform'  // 映射策略
  transform?: (value: any) => any  // 转换函数
  priority?: number             // 优先级（多对一时使用）
}

// 字段状态
interface FieldState {
  name: string
  status: 'unmapped' | 'mapped' | 'ignored' | 'missing'
  mappingId?: string           // 关联的映射ID
  suggestions?: Array<{
    target: string
    confidence: number
    reason: string
  }>
}
```



### Vue 3 组件实现

```typescript
// 状态管理
const sourceFields = ref<FieldState[]>([])      // 左侧待映射字段
const targetFields = ref<FieldState[]>([])      // 右侧目标字段
const mappings = ref<FieldMapping[]>([])        // 中间映射关系

// 计算属性：未映射的字段
const unmappedSourceFields = computed(() => 
  sourceFields.value.filter(f => f.status === 'unmapped')
)

const unmappedTargetFields = computed(() => 
  targetFields.value.filter(f => f.status === 'unmapped' || f.status === 'missing')
)

// 建立映射
function createMapping(source: string | string[], target: string) {
  const sourceArray = Array.isArray(source) ? source : [source]
  
  // 检查映射类型
  const mappingType = sourceArray.length > 1 ? 'many-to-one' : 'one-to-one'
  
  const mapping: FieldMapping = {
    id: generateId(),
    source: sourceArray,
    target: target,
    mappingType: mappingType,
    confidence: 0.9,
    strategy: mappingType === 'many-to-one' ? 'merge' : undefined
  }
  
  mappings.value.push(mapping)
  
  // 更新字段状态
  sourceArray.forEach(s => {
    const field = sourceFields.value.find(f => f.name === s)
    if (field) {
      field.status = 'mapped'
      field.mappingId = mapping.id
    }
  })
  
  const targetField = targetFields.value.find(f => f.name === target)
  if (targetField) {
    targetField.status = 'mapped'
    targetField.mappingId = mapping.id
  }
  
  toast.show(`已建立映射: ${sourceArray.join(', ')} → ${target}`)
}

// 删除映射
function removeMapping(mappingId: string) {
  const mapping = mappings.value.find(m => m.id === mappingId)
  if (!mapping) return
  
  // 恢复字段状态
  mapping.source.forEach(s => {
    const field = sourceFields.value.find(f => f.name === s)
    if (field) {
      field.status = 'unmapped'
      field.mappingId = undefined
    }
  })
  
  const targetField = targetFields.value.find(f => f.name === mapping.target)
  if (targetField) {
    // 检查是否还有其他映射使用这个目标字段
    const otherMappings = mappings.value.filter(
      m => m.id !== mappingId && m.target === mapping.target
    )
    if (otherMappings.length === 0) {
      targetField.status = 'unmapped'
      targetField.mappingId = undefined
    }
  }
  
  // 删除映射
  mappings.value = mappings.value.filter(m => m.id !== mappingId)
  
  toast.show(`已删除映射: ${mapping.source.join(', ')} → ${mapping.target}`)
}

// 智能推荐
async function getSuggestions(sourceField: string) {
  const response = await api.post('/mapping/suggest', {
    source_field: sourceField,
    available_targets: unmappedTargetFields.value.map(f => f.name),
    context: {
      document_type: documentType.value,
      nearby_fields: getNearbyFields(sourceField)
    }
  })
  
  return response.data.suggestions
}
```

### 1. 智能自动映射

```python
# backend/services/auto_mapper.py
class AutoMapper:
    def auto_map(self, source_fields, target_fields, threshold=0.85):
        """
        自动建立高置信度的映射关系
        
        Args:
            source_fields: 源字段列表
            target_fields: 目标字段列表
            threshold: 置信度阈值（默认0.85）
        
        Returns:
            自动建立的映射列表和剩余未映射字段
        """
        auto_mappings = []
        remaining_sources = []
        used_targets = set()
        
        for source in source_fields:
            best_match = self.find_best_match(source, target_fields)
            
            if (best_match and 
                best_match['confidence'] >= threshold and
                best_match['target'] not in used_targets):
                
                auto_mappings.append({
                    'source': [source],
                    'target': best_match['target'],
                    'confidence': best_match['confidence'],
                    'type': best_match['type']
                })
                used_targets.add(best_match['target'])
            else:
                remaining_sources.append(source)
        
        return {
            'auto_mappings': auto_mappings,
            'remaining_sources': remaining_sources,
            'remaining_targets': [
                t for t in target_fields if t not in used_targets
            ]
        }
```

### 2. 映射冲突检测

```typescript
// 检测映射冲突
function detectConflicts(newMapping: FieldMapping): string[] {
  const conflicts: string[] = []
  
  // 检查源字段是否已被使用
  newMapping.source.forEach(source => {
    const existing = mappings.value.find(m => 
      m.source.includes(source) && m.id !== newMapping.id
    )
    if (existing) {
      conflicts.push(
        `源字段"${source}"已映射到"${existing.target}"，` +
        `不能同时映射到"${newMapping.target}"`
      )
    }
  })
  
  // 检查多对一映射是否需要合并策略
  const sameTargetMappings = mappings.value.filter(
    m => m.target === newMapping.target && m.id !== newMapping.id
  )
  
  if (sameTargetMappings.length > 0 && !newMapping.strategy) {
    conflicts.push(
      `目标字段"${newMapping.target}"已有映射，` +
      `需要指定合并策略（优先级/拼接/覆盖）`
    )
  }
  
  return conflicts
}
```

// 保存为模板
async function saveAsTemplate(name: string) {
  const template = {
    name: name,
    mappings: mappings.value.map(m => ({
      source: m.source,
      target: m.target,
      type: m.mappingType,
      strategy: m.strategy
    })),
    created_at: new Date().toISOString()
  }
  
  await api.post('/mapping/templates', template)
  toast.show(`模板"${name}"已保存`)
}

// 应用模板
async function applyTemplate(templateId: string) {
  const response = await api.get(`/mapping/templates/${templateId}`)
  const template = response.data
  
  // 清空现有映射
  mappings.value = []
  
  // 应用模板映射
  template.mappings.forEach(m => {
    // 检查源字段和目标字段是否存在
    const sourceExists = m.source.every(s => 
      sourceFields.value.some(f => f.name === s)
    )
    const targetExists = targetFields.value.some(f => f.name === m.target)
    
    if (sourceExists && targetExists) {
      createMapping(m.source, m.target)
    }
  })
  
  toast.show(`已应用模板"${template.name}"`)
}

## 📋 完整工作流程

### 用户操作流程

1. **进入映射页面**
   - 自动加载提取的字段和目标字段
   - 执行智能自动映射（置信度>85%）
   - 显示自动映射结果和待处理字段

2. **查看自动映射结果**
   - 中间区域显示已建立的映射
   - 可以删除或编辑不正确的映射

3. **手动处理剩余字段**
   - 左侧显示未映射的源字段
   - 右侧显示未映射的目标字段
   - 通过拖拽或点击建立映射

4. **处理特殊情况**
   - 多对一：选择多个源字段，拖到一个目标字段，选择合并策略
   - 忽略字段：右键点击源字段，选择"忽略"
   - 缺失字段：右侧目标字段标记为"缺失"，可设置默认值

5. **预览和确认**
   - 查看映射预览表格
   - 确认无误后点击"应用映射"

6. **保存和导出**
   - 可选：保存为模板供下次使用
   - 应用映射并下载结果文件

    data = request.json
    source_field = data.get('source_field')
    available_targets = data.get('available_targets', [])
    context = data.get('context', {})

        source_field,
