# 字段配置使用说明

## 📁 配置文件

包含两个字段配置JSON文件，用于前端协议字段匹配：

### 1. 核心字段配置.json (推荐使用)
- 包含最常用的16个协议字段和16个目标字段
- 适合大多数文档处理场景
- 文件较小，加载速度快

### 2. 字段配置模板.json 
- 包含完整的38个协议字段和26个目标字段
- 覆盖更全面的字段类型
- 适合复杂文档处理需求

## 🚀 使用方式

### 前端导入（推荐）
1. 访问前端界面：http://localhost:5173
2. 进入"字段配置"页面
3. 点击"导入字段（JSON）"按钮
4. 选择JSON文件上传

### 配置文件说明
配置文件采用JSON格式，结构简单明了，可直接在前端界面导入使用。

## 📊 字段对应关系

### 协议字段 (Protocol Fields)
这些是从文档中提取的原始字段名称：

- 序号、参数、内容、信号名称
- 数据类型、类型、长度、字节
- 单位、备注、值域
- 信源、信宿、信息内容
- 消息ID、接口名称

### 目标字段 (Target Fields)  
这些是标准化的目标字段名称：

- ID、内容、转换类型、类型（bit）
- 信源系统码、信源机器码
- 信宿系统码、信宿机器码
- 子地址、备注、信息标识
- 信号名称、数据类型、字节数
- 单位、取值范围

## 🔧 自定义配置

如果需要自定义字段，可以：

1. 编辑JSON文件，添加或删除字段项
2. 保持JSON格式正确
3. 确保每个字段都有唯一的id和name

### 字段格式示例：
```json
{
  "id": "唯一标识符",
  "name": "字段显示名称"
}
```

## 💡 使用建议

- **入门用户**：使用"核心字段配置.json"（字段精简，处理速度快）
- **高级用户**：使用"字段配置模板.json"（字段完整，匹配更精确）
- **个性化需求**：基于现有文件修改调整

**注意事项**：
- JSON导入会自动去重合并，安全可靠
- 前端修改无需重启服务，即时生效
