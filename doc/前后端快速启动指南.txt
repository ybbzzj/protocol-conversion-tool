⚠️  常见问题及解决:

  Q: 错误: "Address already in use"?
  A: 端口被其他程序占用。查看占用进程:
     lsof -i :5000      # 查看 5000 端口
     lsof -i :5001      # 查看 5001 端口
     
     macOS 常见占用者: ControlCenter (AirPlay Receiver)
     解决方案: 关闭 AirPlay Receiver 或改用其他端口
     python3 -c "from backend.app import create_app; app = create_app(); \
       app.run(host='0.0.0.0', port=5002, debug=True)"

  Q: 错误: "Could not locate a Flask application"?
  A: 说明 Flask 无法找到 app。确保:
     - 已进入虚拟环境
     - 当前目录是项目根目录
     - 使用本指南中的启动命令

  Q: 模块导入错误，如 "No module named 'backend.app'"?
  A: 虚拟环境未激活。执行:
     source venv/bin/activate

【常见问题完全指南】
───────────────────────────────────────────────────────────────────────────

1. macOS 系统 Python 限制
   ├─ 错误: "error: externally-managed-environment"
   ├─ 原因: macOS Ventura+ 禁止直接 pip install
   ├─ 解决:
   │   python3 -m venv venv
   │   source venv/bin/activate
   │   pip install -r backend/requirements.txt
   └─ 验证: which python 应显示 venv 中的 Python

2. 端口被占用
   ├─ 错误: "Address already in use"
   ├─ 诊断:
   │   lsof -i :5000
   │   lsof -i :5001
   │   lsof -i :5173
   ├─ 解决:
   │   - 关闭占用程序
   │   - 或改用其他端口 (5002, 5003 等)
   └─ macOS 特例: AirPlay Receiver 占用 5000
       → 系统设置 → 通用 → AirDrop → 关闭 AirPlay Receiver

3. npm 安装缓慢/失败
   ├─ 原因: npm 官方源在国内速度慢
   ├─ 解决:
   │   npm config set registry https://registry.npmmirror.com
   │   npm cache clean --force
   │   npm install
   └─ 恢复默认源:
       npm config set registry https://registry.npmjs.org/

4. 权限错误 (Permission denied)
   ├─ 错误示例: "sh: /path/node_modules/.bin/vite: Permission denied"
   ├─ 原因: node_modules 中的可执行文件缺少执行权限
   ├─ 解决:
   │   cd /Users/yuanyuqing/Documents/code/schoolProject/public
   │   chmod +x node_modules/.bin/*
   │   npm run dev
   └─ 一键修复: chmod -R +x node_modules/.bin/

5. 模块导入错误
   ├─ 错误: "ModuleNotFoundError: No module named 'flask'"
   ├─ 原因1: 虚拟环境未激活
   │   → source venv/bin/activate
   ├─ 原因2: 依赖未安装
   │   → pip install -r backend/requirements.txt
   └─ 原因3: Python 路径错误
       → which python 应显示 venv 中的路径

6. Flask 应用找不到
   ├─ 错误: "Could not locate a Flask application"
   ├─ 原因: 未正确指定 Flask app
   ├─ 解决: 使用本指南中的启动命令
   │   python3 -c "from backend.app import create_app; ..."
   └─ 不要用: python -m flask run

7. 前端无法连接后端
   ├─ 症状: 浏览器控制台显示 CORS 或连接错误
   ├─ 检查步骤:
   │   1. 后端是否运行: curl http://localhost:5001/health
   │   2. 端口是否正确: 后端 5001，前端 5173
   │   3. 代理配置: 检查 public/vite.config.ts
   └─ 解决: 重启后端和前端

8. 文件上传失败
   ├─ 原因1: backend/uploads/ 权限不足
   │   → chmod -R 755 backend/uploads/
   ├─ 原因2: 磁盘空间不足
   │   → df -h 检查
   └─ 原因3: 文件格式不支持
       支持格式: .doc, .docx, .xlsx, .xls, .csv

9. Excel 导出失败
   ├─ 原因: backend/outputs/ 无写入权限
   ├─ 解决:
   │   chmod -R 755 backend/outputs/
   └─ 验证:
       touch backend/outputs/test.txt && rm backend/outputs/test.txt

10. 后端无法启动 (各种原因)
    ├─ 步骤1: 检查虚拟环境
    │   source venv/bin/activate
    ├─ 步骤2: 验证依赖
    │   pip list | grep flask
    ├─ 步骤3: 测试导入
    │   python3 -c "from backend.app import create_app; print('OK')"
    ├─ 步骤4: 查看完整错误
    │   python3 app.py 2>&1 | head -50
    └─ 步骤5: 查看日志
        tail -f backend/logs/extraction_trace.log

【数据流完整过程】
───────────────────────────────────────────────────────────────────────────

用户交互流程:

1. 用户打开浏览器 → http://localhost:5173/ (前端加载)
   ↓
2. 前端发起 API 调用 → http://localhost:5001/api/dashboard/recent
   (前端代理自动转发，见 vite.config.ts)
   ↓
3. 后端处理请求，返回 JSON 响应
   ↓
4. 前端渲染数据到页面
   ↓
5. 用户上传 Word/Excel 文档
   ↓
6. 前端发起 POST /api/extract/start (multipart/form-data)
   ↓
7. 后端:
   a) 保存临时文件到 backend/uploads/
   b) 解析文档，提取表格数据
   c) 使用知识库进行模糊匹配
   d) 返回提取结果（含匹配建议）
   ↓
8. 前端显示表格数据和建议匹配
   ↓
9. 用户手动调整字段映射 (可选)
   ↓
10. 用户点击 "导出"
    ↓
11. 前端发起 POST /api/extract/export
    ↓
12. 后端:
    a) 根据映射生成 Excel 文件
    b) 保存到 backend/outputs/
    c) 返回下载链接
    ↓
13. 前端显示下载按钮，用户点击下载文件
    ↓
14. 完成！清理临时文件
