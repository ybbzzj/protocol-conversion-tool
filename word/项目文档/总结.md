# Word协议表格信息提取系统 - 项目总结报告

## 一、项目概述

### 1.1 项目背景
本项目是一个**Word协议表格信息智能提取与匹配系统**，用于从Word文档中自动识别和提取通信协议的表格信息，并将提取的数据字段智能映射到标准目标字段，最终生成规范化的Excel输出文件。

系统支持多种格式的协议文档（.doc、.docx），通过多策略表头识别、智能字段匹配、数据清洗与转换等核心功能，实现协议文档的自动化处理，大幅提升工作效率。

## 二、功能模块实现总结

### 2.1 文档解析模块

**模块路径**: `backend/services/table_detector.py`

**核心功能**:
- 支持 `.doc`、`.docx`、`.xlsx`、`.xls`、`.csv` 文件解析
- 多策略表头识别：
  - 策略一：关键字检测（检测"数据类型"、"单位"等标准列关键字）
  - 策略二：结构分析（分析行列数变化识别表头位置）
  - 策略三：智能推断（对于复杂表格自动推断表头行）
- 单元格文本提取与清洗
- 表格行列数据解析

**关键数据结构**:
```python
# 解析结果格式
{
    'tables': [
        {
            'index': 0,
            'msg_name': '表名称',
            'table_type': 'field_def',
            'headers': ['列1', '列2', ...],
            'data_rows': [{'col1': 'val1', ...}, ...],
            'meta': {'源文件': 'xxx.docx', ...}
        }
    ]
}
```

### 2.2 表格关联模块

**模块路径**: `backend/services/table_linker.py`

**核心功能**:
- 表格类型分类（field_def主表、bit子表、辅助表）
- 位定义行识别与注入
- 辅助表过滤（端口分配表、消息ID表等不输出到Excel）
- 表格元数据注入与来源追踪

### 2.3 字段匹配模块

**模块路径**: `backend/services/field_matcher.py`

**核心功能**:
- **三层优先级匹配**：
  1. 精确匹配（知识库中完全一致的映射）
  2. 模糊匹配（基于相似度计算）
  3. 语义匹配（基于上下文的智能推荐）
- **知识库管理**：
  - 映射关系持久化存储
  - 命中率统计与更新
  - 置信度评分
- **智能推荐**：
  - 考虑上下文可用目标字段
  - 多维度相似度计算

### 2.4 数据清洗模块

**模块路径**: `backend/services/data_cleaner.py`

**核心功能**:
- 单元格值清洗（去除多余空白、换行符）
- 数据类型推断（int、float、string、enum）
- 邮箱和电话格式验证
- 数值清洗与标准化
- 文本标准化处理
- 缺失值处理策略
- 转换公式结构化提取
- 值域信息提取

### 2.5 Excel导出模块

**模块路径**: `backend/services/excel_exporter.py`

**核心功能**:
- 数据写入Excel工作表
- 表头美化：
  - 蓝色背景（RGB: 68, 114, 196）
  - 白色加粗文字
  - 居中对齐
- 列宽自动调整
- 表头冻结
- 边框设置
- 多表分别导出

## 五、核心处理流程

### 5.1 文档提取流程

```
用户上传Word文档 + 选择协议字段
         ↓
    文件格式验证
         ↓
    创建任务记录 (status=running)
         ↓
    文档解析 (DocumentParser)
         ├─ 表格检测
         ├─ 表头识别
         └─ 数据提取
         ↓ (progress: 10% → 50%)
    表格关联处理 (TableLinker)
         ├─ 类型分类
         ├─ 过滤辅助表
         └─ 注入bit子行
         ↓
    数据清洗 (DataProcessor)
         ├─ 值清洗
         ├─ 类型推断
         └─ 格式转换
         ↓
    字段匹配 (FieldMatcher)
         ├─ 精确匹配
         ├─ 模糊匹配
         └─ 智能推荐
         ↓ (progress: 50% → 90%)
    Excel导出 (ExcelExporter)
         ↓ (progress: 90% → 100%)
    更新任务状态 (status=success)
         ↓
    返回 task_id 给前端
```

### 5.2 字段映射质量评估

系统自动计算映射质量评分：

```python
映射质量 = (精确匹配数 × 1.0 + 模糊匹配数 × 0.7) / 总字段数

等级划分:
- excellent: score > 0.9
- good: 0.7 < score <= 0.9
- poor: score <= 0.7
```
