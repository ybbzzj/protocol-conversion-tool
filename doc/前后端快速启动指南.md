# 🚀 前后端快速启动指南

> **提示：** 将 `/path/to/your/project` 替换为你实际的项目路径

## ⚡ 一句话启动（推荐新手）

**macOS/Linux：**
```bash
# 第一次使用（安装依赖）
cd /path/to/your/project && python3 -m venv venv && source venv/bin/activate && pip install -r backend/requirements.txt && cd public && npm install && cd ..

# 启动服务（两个终端分别运行）
# 终端1：source venv/bin/activate && python3 -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"
# 终端2：cd public && npm run dev
```

**Windows：**
```cmd
# 第一次使用（安装依赖）
cd C:\path\to\your\project && python -m venv venv && venv\Scripts\activate && pip install -r backend\requirements.txt && cd public && npm install && cd ..

# 启动服务（两个命令提示符分别运行）
# CMD1：venv\Scripts\activate && python -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"
# CMD2：cd public && npm run dev
```

## 🔧 环境准备

**系统要求：**
- Python 3.8+ (推荐 3.10+)
- Node.js 16+ (推荐 18+)
- npm 8+

**验证命令：**
```bash
python3 --version    # 预期: Python 3.8+
node --version       # 预期: v16+
npm --version        # 预期: 8.0+
```

## ⚡ 三步启动

### 第一步：安装依赖

**macOS/Linux版本：**
```bash
# 进入项目根目录
cd /path/to/your/project

# 创建并激活虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt

# 安装前端依赖
cd public && npm install && cd ..
```

**Windows版本：**
```cmd
# 进入项目根目录
cd C:\path\to\your\project

# 创建并激活虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate
pip install -r backend\requirements.txt

# 安装前端依赖
cd public && npm install && cd ..
```

### 第二步：启动后端服务

**macOS/Linux版本：**
```bash
# 终端1 - 后端
cd /path/to/your/project
source venv/bin/activate
python3 -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"
```

**Windows版本：**
```cmd
# 命令提示符1 - 后端
cd C:\path\to\your\project
venv\Scripts\activate
python -c "from backend.app import create_app; app = create_app(); app.run(host='0.0.0.0', port=5001, debug=True)"
```

### 第三步：启动前端服务

**macOS/Linux版本：**
```bash
# 终端2 - 前端
cd /path/to/your/project/public
npm run dev
```

**Windows版本：**
```cmd
# 命令提示符2 - 前端
cd C:\path\to\your\project\public
npm run dev
```

## 🛠️ 常见问题解决

### 1. Python 环境问题
**错误：** "error: externally-managed-environment"

**macOS/Linux解决方法：**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows解决方法：**
```cmd
python -m venv venv
venv\Scripts\activate
```

### 2. 端口被占用

**macOS/Linux诊断：**
```bash
lsof -i :5001  # 检查后端端口
lsof -i :5173  # 检查前端端口
```

**Windows诊断：**
```cmd
netstat -ano | findstr :5001  # 检查后端端口
netstat -ano | findstr :5173  # 检查前端端口
```

**解决：** 更换端口或关闭占用程序

### 3. npm 安装缓慢
**解决：** 切换国内镜像
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 4. 权限错误

**macOS/Linux解决方法：**
```bash
chmod +x node_modules/.bin/*
npm run dev
```

**Windows说明：** Windows通常不会遇到此问题，如遇权限问题请以管理员身份运行命令提示符。
